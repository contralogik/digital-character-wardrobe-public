## 后续换装

1. 先读取[长期换装规则](try-on-rules.md)、[身材基准表](body-baselines.md)、[发型区分规则](hairstyle-guide.md)及对应人物卡。
2. 面部、发型和妆容使用上表新版；保持各人独立的眼形、脸型和五官关系。
3. 颈部以下维持身体基准表指定比例：欣然、鹿儿、蓉儿沿用 v1，羊羊子和蜜蜜沿用 v2。旧基准的脸与头发不覆盖新版。
4. 蜜蜜保留“腿细直”：修长纤细、自然顺直，保留膝盖和小腿体量。
5. 继续校准相貌时，用户需在任务中另行提供原始照片；避免仅用生成脸反复派生。

身高、杯型是虚拟角色背景设定；图像没有精确尺寸标定。衣服、表情和姿势可变，底层身体比例保持固定。
