## 后续换装参考顺序

第一套换装的[服装参考、提示词与五人成图](outfits/01-pink-floral/README.md)已保存。五张为居家自然光镜前自拍，披散造型，均为 941 × 1672 PNG；原样服装版本未通过图像工具输出审核，成功版本增加不透明内衬并收拢胸前开口，按人物保存在 outfits/01-pink-floral 目录。

开始换装前先读取 [try-on-rules.md](try-on-rules.md) 和 [body-baselines.md](body-baselines.md)，再按以下顺序选择对应人物资料。

发型同时读取 [hairstyle-guide.md](hairstyle-guide.md)，旧身体参考图的发髻与卷度不覆盖当次造型要求。

1. 读取相应人物特征卡，保留用户已确定的身高、发色等设定。
2. 在当前任务中另行提供人物原照以校准相貌；公开版不含人物原照。滤镜、自拍透视或服装挤压不覆盖长期规则。
3. 使用身材基准表指定的全身图维持该角色的虚拟身体比例；其中未被原照清晰展示的部分仍属于生成补全，不作为真人尺寸资料。
4. 衣服改变布料轮廓、垂坠与遮挡，保持底层肩胸廓腰胯、头身关系和腿部比例；发型、妆容、地点与自拍方式按选定版本继承。
5. 新版本保留旧文件，避免只用生成图反复生成而累积相貌偏差；永久固定项目只在用户明确要求调整该项时更新。

若在新对话继续工作，可提供此索引、长期换装规则、对应人物特征卡、指定全身基准图以及原始参考照片。
