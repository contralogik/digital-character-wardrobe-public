# 五人发型区分规则

发型属于半固定造型。各人有默认方向，可按服装、场景或用户要求更换；不能只因读取旧身体基准图，就自动恢复旧发型。脸、年龄感、身材比例、基础肤色和基础气质继续固定。

## 默认方向与全部披散时的区别

| 人物 | 默认造型方向 | 当次要求全部披散时 |
| --- | --- | --- |
| 欣然 | 深棕近黑色长发，较低的后部半扎，余发顺直披散，少量长碎发 | 近中分的顺直长发，长度到胸下至腰部，发梢仅轻弯，头顶体积收敛 |
| 鹿儿 | 较浅暖栗棕发色，低位单侧松辫，轻薄额前碎刘海 | 轻薄空气感刘海、暖栗棕长发，柔和轻微 C 弯，不作与欣然相同的无刘海黑长直 |
| 蓉儿 | 深色蓬松长大波浪 | 保留有辨识度的松散 S 形大波浪与较明显发根体积 |
| 羊羊子 | 黑色齐肩偏分短发；顺直长发保留为可选版本 | 默认沿用自然披散的齐肩短发，不自动改成长发；用户选择长发版本时另记 |
| 蜜蜜 | 深色低位松扎发，颈后松扭聚拢，露出较多额头 | 较明显侧分，主体更顺滑、卷度较低，只在下段或发尾少量松弯；头顶体积较收敛，不复制蓉儿的整头大波浪 |

## 执行顺序

1. 用户当次指定优先。例如第一套换装要求全部披散，就使用上表的披散方向，不使用默认扎发。
2. 未指定时读取各人物默认方向，允许为服装和多人同框做适度调整，记录选用版本。
3. 多人同框优先通过扎法、卷度、长度、分缝与额前发丝的组合区分，不仅靠发色；不把欣然与鹿儿同时做成同样的高发髻，也不把蓉儿与蜜蜜做成同样的蓬松长大波浪。
4. 调整头发不改变头骨大小、发际线以外的面部轮廓、五官或头身关系；发髻高度不当作身体身高。
5. 身体基准图继续用于体型校准，其旧头发与当前造型要求冲突时，以本规则和当次请求为准。

第一套换装已选用各人的披散版本；手机镜前自拍、自然室内光与手机 RAW 观感属于当次拍摄设定。
