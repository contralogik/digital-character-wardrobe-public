# 五人发型区分规则

更新于 2026-09-30，与[新版参考总表](reference-refresh-2026-09-30.md)及各人物当前特征卡共同使用。发型属于半固定造型，未指定时用以下默认版本；用户当次明确指定优先。

## 默认发型与全部披散时的区别

| 人物 | 默认造型方向 | 当次要求全部披散时 |
| --- | --- | --- |
| 欣然 | 近黑深棕长发，低位后部半扎、余发顺直，近中分、少量长碎发、额前较开放 | 近中分顺直长发，胸下至腰部附近，发梢轻弯，头顶体积收敛 |
| 鹿儿 | 暖栗棕、略深发根，轻薄空气感碎刘海，低位单侧松辫落在一侧肩前 | 暖栗棕长发、轻薄刘海与轻微 C 弯，保留柔和脸侧碎发 |
| 蓉儿 | 深棕近黑长卷发、明确侧分、发根抬起，中上段以下连贯的大 S 波浪，露出一侧眉眼与面颊 | 沿用整理过的大 S 波浪与明确发根体积，减少横跨脸部的杂乱碎发 |
| 羊羊子 | 近黑齐肩短发、清楚偏分、轻盈层次，一侧可别耳后，发尾在肩部附近 | 默认仍为齐肩短发；顺直长发保留为用户可选版本，选用时记录 |
| 蜜蜜 | 用户最新选定的侧分黑色长发：脸侧宽松外翻弯，一侧别耳并落后，另一侧长发更多垂于肩前；上段流畅、松散长 S 弯向下延续 | 默认已为披发，保持侧分、脸侧扫发及不对称垂落关系；低位松扎仅保留为可选 |

## 面容与妆发共同区分

- 欣然：偏长鹅蛋脸、细长杏眼、平静目光、自然轻妆；鹿儿：更饱满面颊、圆润成年杏眼、小圆下巴、温暖轻妆。更换头发也要维持各自面容，不能只靠发色识别。
- 蓉儿：明显的侧分大 S 波浪、发根体积、暖灰棕眼妆与玫瑰木唇；蜜蜜：黑色侧分长发、脸侧外翻松弯、一侧别耳与另一侧肩前垂落、原照重校的六宫格面容。两人不共用整头蓬松大卷。
- 羊羊子：齐肩短发为默认轮廓，保留原有杏眼、低眉峰、自然鼻唇和克制气质，不靠接发换脸。

## 执行顺序

1. 读取用户当次要求、人物当前特征卡和本规则；没有发型要求时继承当前默认版本。
2. 多人同框结合分缝、额前发丝、扎法、卷度与长度区分，同时使用各自最新面部图，不将欣然与鹿儿都恢复成旧高发髻。
3. 头发调整不改变五官、成年年龄感、身体比例与基础肤色；发髻高度不当作身体身高。
4. 旧身体基准图只用于颈部以下比例，旧头发与当前造型冲突时按本规则执行。
5. 首套粉色换装等历史作品保留其当时造型；不能因规则更新将旧图称为已同步新版。
